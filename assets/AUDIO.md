# One-Touch Striker audio provenance

All 16 WAV files in `audio/` are original procedural assets made for this
project with `tool/generate_audio.py`. The melodies, instruments, percussion
and crowd textures are synthesized in that script. No third-party recordings,
sample packs, song excerpts, recorded voices, team chants or external downloads are used.
The fan sounds are a stylized synthetic crowd, not recorded spectators.
These assets can be used and modified with the game, including its commercial
release; there are no third-party sample attribution requirements for this pack.

Format: mono, 16-bit PCM, 22,050 Hz. The complete pack occupies **1,824,240 bytes**
before APK compression. Uncompressed WAV avoids encoder padding in the musical
loops; actual loop continuity and the mix still need Android/iPhone listening.

Clip durations are declared in `ShotSound` in `lib/game/audio_cues.dart`; keep
them synchronized when replacing an effect. Android's low-latency mode has no
completion event, so the controller uses each duration plus a 60 ms margin.
All new assets have bounded peaks and a softened boundary. The original seven
effects are regenerated byte for byte without changing their established mix.

Only `assets/audio/` is bundled by Flutter. This document and the generator add
no runtime work. Regenerate from the repository root using standard Python 3:

```bash
python3 tool/generate_audio.py
```

Asset metadata, PCM peaks and file edges were inspected during publication.
No Flutter analyzer, tests, builds, app execution, native audio playback or
GitHub workflows were run. See [the audio milestone handoff](../AUDIO_EXPERIENCE.md)
for the sound rules, settings and remaining local listening checks.
